# 恺悌智算 · 发行版

这里是 **恺悌智算（H3 Studio）** 的安装包下载页。源码不公开，这个仓库只放能直接装的产物。

> 桌面客户端：把 ComfyUI 工作流包成「一张卡一件事」的界面（MiniMax H3 / Wan 2.1 / SCAIL-2 / Qwen-Image / MOSS-Image 等），
> 跑在你自己的机器或你自己的 ComfyUI 服务器上。

## 下载

最新一版都在同一个地方 —— [**最新发行版**](../../releases/latest)（标签固定为 `build-latest`，每次发版覆盖，只留最新一版）。

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11 x64 | `h3-studio_<版本>_x64_zh-CN.msi` | 双击安装。装完在开始菜单里找「恺悌智算」 |
| macOS（Intel / Apple 芯片通用） | `h3-studio_<版本>_universal.dmg` | **未签名**：首次打开若提示"无法验证开发者"，右键 → 打开，或到「系统设置 → 隐私与安全性」点"仍要打开" |
| Linux x64 | `h3-studio_<版本>_amd64.deb` / `_amd64.AppImage` | deb 用 `sudo apt install ./xxx.deb`；AppImage 加执行位后直接运行 |

文件名里的版本号就是软件版本（例如 `_0.3.174_`）。装完可以在客户端「设置」里核对。

## 每个包自带的东西

- **随包一份 ffmpeg**（`h3-ffmpeg`），视频裁剪/帧区间等功能开箱可用，不需要你自己装。
- 运行需要 **WebView2**（Windows 11 自带；Windows 10 若缺失，安装包会提示并给出下载地址）。
- 只是客户端：**要出图/出视频，你得有能连上的 ComfyUI**（本机或局域网/远程都行），并且服务器上装了对应的模型与节点。

## 常见问题

**为什么 Releases 里只有一个标签、只有最新一版？**
附件不计入配额、但会一直堆着，所以滚动覆盖。旧版本要的话，联系开发者按版本号重出。

**下载很慢 / 中断？**
走的是 GitHub 的 CDN。国内网络建议用支持断点续传的下载工具，或换个时段。

**这是开源软件吗？**
不是。这里只提供可执行产物；源码与工作流定义不对外。
